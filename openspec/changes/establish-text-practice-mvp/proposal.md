# Establish text practice MVP

## Why

A technical leader needs repeated practice explaining decisions, handling objections and presenting architecture in English. The repository has no application yet. A local, text-first prototype makes the practice loop usable without credentials, cloud costs or premature claims about automated coaching.

## What changes

- Add three professional practice tracks with staged, unrevealed prompts and saved responses.
- Add manual expression capture and a spaced review queue.
- Save sessions locally, show history and allow JSON export and deletion.
- Document pedagogical rationale and limits, then plan later AI feedback and voice practice separately.

## Scope and success

Single learner, one browser, English prompts, text answers. A learner can complete a session, return to history, add an expression, reveal and review it, and export/delete data. No automated grammar grading, conversation agent, speech analysis, account or sync is included.
