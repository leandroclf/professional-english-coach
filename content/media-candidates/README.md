# Candidate lesson media

Files in this directory are authoring sources. The current learner-facing MP3 is copied to `src/assets/audio/` and is included in the static build under the owner's explicit personal-use authorization. Generate a replacement with `bash scripts/generate-audio-candidate.sh`, then compare its script, duration and size before promoting it.

`tradeoff-phrase.mp3` is a short English TTS clip generated locally by FFmpeg using its libflite `kal` voice. It uses no reference recording or cloned identity. The owner authorized use for personal and family learning and accepted publication on the existing public Site. Pronunciation and tool/voice output rights were not independently reviewed; this is recorded as an accepted project risk rather than legal clearance. The script transcript is provided in the application.

The optional Colab notebook can inspect authored media metadata or preview a clip, but is not a release gate. Do not upload learner recordings, secrets, or confidential source material.
